# Vendor Risk Management Lab

## Overview
This project simulates a third-party risk management workflow by assessing mock vendors based on data sensitivity, business criticality, and security control maturity.

## Components
- Vendor inventory
- Vendor security questionnaire
- Risk scoring model
- Assessment report
- Remediation tracker

## Skills Demonstrated
- Third-party risk management
- Vendor due diligence
- Risk tiering
- Residual risk assessment
- Remediation tracking
- Compliance-style documentation

## Key Outcome
This lab demonstrates how vendor risks can be identified, assessed, communicated, and tracked through a structured GRC process.
